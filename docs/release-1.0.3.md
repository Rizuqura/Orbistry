# 1.0.3 Victoria (Beta)

Worldbuilding update

- Interactive isometric WorldView with camera pan, cursor-centered zoom, reset, and a fading grid.
- Create, customize, move, and delete entity chips with confirmation.
- Assign existing Universe files through a searchable folder picker and save associations in Markdown metadata.
- File buildings show byte-based heights, arranged from largest at the top corner to smallest toward the bottom.
- PDF buildings are light red, Markdown blue, CSV light yellow, and PNG/JPEG white.
- Centered custom icons and complete chip titles.
- File inspection and confirmed unassignment preserve original Universe files.
- The top bar and loading screen display v1.0.3 Victoria (Beta).
